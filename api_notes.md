# API Notes

## Endpoint
An endpoint is the URL where an API receives requests, which eachpoint performs a specific task.
## Request
This is the message you send to the server. It tells the server exactly what you need.
## Response
A response is the information returned by the API after it processes a request.
## JSON
JSON (JavaScript Object Notation) is the common language used to format the information inside a message.
## Status Code
A status code is a number returned by the server to show whether a request was successful or failed.
- 200– Okay
- 401- Unauthorized
- 404– Not Found
- 500– Internal Server Error
