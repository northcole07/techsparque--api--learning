# TechSparque Learning Tracker API- Project Plan
## Project Overview
The TechSparque Learning Tracker API is a simple FastAPI project that helps track students' learning progress during their internship.

## Features
### Students
- View student information
- Register new students

### Topics
- Add, store and view learning topics
- Assign topics to students

### Completion
- Mark topics as completed or not completed
- Track each student's progress

### Notes 
- Add and edit notes
- View notes for a student

## Future Improvements
- Add due dates for each topic
- Calculate each student's completion percentage
- Search for students or topics
- Add a login function for mentors and students
